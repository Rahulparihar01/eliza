### Participants & Actions

| Actor | Role | Actions Performed |
|-------|------|-------------------|
| **Deal Team Partner** | Question Asker | • Opens Eliza Chat<br>• Types natural language question<br>• Clicks to drill into specific deals<br>• Saves query as reusable template |
| **Eliza (System)** | Intelligence Connector | • Recognizes cross-source question<br>• Queries DealCloud for sourcing data<br>• Queries Chronograph for outcomes<br>• Synthesizes and presents ranked analysis |
| **DealCloud** | History Provider | • Provides deal sourcing data<br>• Provides relationship networks<br>• Provides team activity records |
| **Chronograph** | Performance Provider | • Provides IRR and MOIC by deal<br>• Provides value creation timeline<br>• Provides current portfolio metrics |

### The Old Way vs. The New Way

| Old Reality | New Reality |
|-------------|-------------|
| 3-week analyst project | 60-second conversation |
| Manual data reconciliation | Automatic cross-source join |
| Static PowerPoint deliverable | Living, refreshable insight |
| Answer forgotten by arrival | Insight saved for future use |

### Value Statement

> **"Proprietary deals create 2.3x more value on average"**
> 
> This insight—which would have required a dedicated analyst project—now emerges from a single question. The partner can immediately adjust sourcing strategy with data backing.

### Participants & Actions

| Actor | Role | Actions Performed |
|-------|------|-------------------|
| **PortCo CFO** | Data Provider | • Downloads Excel template<br>• Fills in quarterly metrics<br>• Uploads completed file<br>• Adds narrative context explaining variances<br>• Sets status to "Shared"<br>• Attaches supporting documents |
| **Eliza (System)** | Validator & Connector | • Validates uploaded data<br>• Flags significant changes from trend<br>• Prompts for context on anomalies<br>• Notifies HoldCo of new submission<br>• Versions all changes |
| **HoldCo Ops** | Reviewer | • Receives notification<br>• Reviews metrics with context<br>• Asks follow-up questions if needed |

### The Old Way vs. The New Way

| Old Reality | New Reality |
|-------------|-------------|
| 47 emails requesting updates | One-click template download |
| "Why did margin drop?" buried in thread | Context visible alongside number |
| Which version is current? | Single versioned source of truth |
| CFO's explanation lost after board meeting | Explanation preserved permanently |

### Value Statement

> **CFO's 30 seconds of context saves 3 days of back-and-forth**
> 
> The narrative explaining margin compression travels with the metric forever. When the board asks "why?", the answer is already there—attributed, versioned, and ready.
