# eliza-rag-ingestion

Portable RAG ingestion and retrieval package extracted from Eliza Platform.

## Included modules

- `eliza_rag.embeddings`
- `eliza_rag.vector_store`
- `eliza_rag.retrieval`
- `eliza_rag.chat`
- `eliza_rag.chunking`
- `eliza_rag.document_parser`
- `eliza_rag.metadata_enrichment`

## Install from local folder

```bash
pip install ./packages/eliza-rag-ingestion
```
