## How to View

### In GitHub/GitLab
Mermaid diagrams render automatically in markdown preview.

### In VS Code
Install the "Markdown Preview Mermaid Support" extension.

### In Cursor
Mermaid diagrams render in the markdown preview pane.

### Export to Image
Use [Mermaid Live Editor](https://mermaid.live/) to export as PNG/SVG.

---

## Creating New Diagrams

1. Create a new `.md` file in this directory
2. Use fenced code blocks with `mermaid` language identifier
3. Add context and description around the diagram
4. Update this README with the new diagram
